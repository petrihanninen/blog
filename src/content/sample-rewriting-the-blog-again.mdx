title: Rewriting the Blog, Again
date: 2026-07-03
lede: Third rewrite in two years. This time with a rule that there is nothing left to remove.
---

Every rewrite started with the same question: what is actually needed here? The answer kept getting shorter. This time the whole thing fits in a handful of files.

### The entire data layer

```ts
export const getBlogs = async () => {
  const files = fs.readdirSync(contentDir).filter(file => file.endsWith('.mdx'))
  return Promise.all(files.map(file => getBlogBySlug(path.parse(file).name)))
}
```

No database, no CMS, no admin panel. A post is a file. Publishing is a `git push`. If I ever need more than this, I will probably need a lot more, and that is a different project.

### Things that got cut

1. Tags and categories. I never used them to find anything.
2. Comments. Email works.
3. Analytics. Knowing the number did not change what I wrote.

Everything left on the page is there because removing it would break something.
