---
title: Aim Training Is Just Deliberate Practice
date: 2025-11-20
lede: Twenty minutes a day in a grey room shooting spheres taught me more about learning than any course.
---

I play a lot of shooters. For a long time I assumed that aim was something you either had or did not, and that playing more would sort it out. It did not. My rank stayed exactly where it was for two years.

Then I spent a month doing structured aim training. Twenty minutes, every day, before any actual games.

### What changed

1. I isolated one skill at a time. Tracking one week, flicking the next.
2. I measured it. Same scenario, same length, score written down.
3. I stopped when the score dropped. Tired practice is negative practice.
4. I rested. Two days off a week, no exceptions.

The rank moved within three weeks. Not because the drills are magic but because for the first time I was practicing the thing instead of doing the thing.

### The obvious parallel

This is deliberate practice as described in every book about expertise. Isolate, measure, rest, repeat. I knew all of that. I had just never applied it to anything I did for fun, because fun was supposed to be the opposite of practice.

The same month I started doing it with climbing. And, embarrassingly late, with programming. Twenty minutes of reading code I did not write, with a specific question in mind, beats an afternoon of unfocused tinkering.

### A caveat

None of this makes the games more fun. It makes you better, which is a different thing. Decide which one you are after before you start writing scores down.
